《无畏二战》隐私政策

更新日期：2026年11月1日
生效日期：2026年11月1日

草居工作室（以下简称“我们”）是《无畏二战》（以下简称“本游戏”）的开发者。我们非常重视用户的隐私和个人信息保护。在您使用本游戏的过程中，我们可能会收集和使用您的相关信息。我们希望通过本《隐私政策》向您说明，我们如何收集、使用、存储和保护这些信息。

一、 我们如何收集和使用您的信息

本游戏为轻量级单机策略游戏，我们不会主动收集您的真实姓名、身份证号、手机号、地理位置等任何敏感个人身份信息。

在您使用本游戏时，我们会通过以下方式收集必要的非敏感信息：

1. 本地游戏数据存储：为了保存您的游戏进度（如金币数量、卡牌等级、通关记录等），我们会使用 TapTap 提供的本地存储接口将数据保存在您的设备本地。这些数据不会上传至我们的服务器，卸载游戏或清理缓存会导致数据丢失。

2. 广告服务：为了维持游戏的免费运营，本游戏接入了 TapTap 广告服务。当您主动选择观看“激励视频”广告时，第三方广告 SDK 可能会收集您的设备标识符（如 OAID/IDFA）、设备型号、网络状态等基础信息，用于广告的精准投放与防作弊校验。

二、 第三方 SDK 服务

为了保障游戏的正常运行和广告变现，我们接入了 TapTap 官方 SDK。关于第三方 SDK 的具体信息收集与隐私保护规则，请参考其官方文档：

SDK 名称：TapTap SDK (包含 TapTap 广告模块)
运营主体：易玩（上海）网络科技有限公司
使用目的：提供本地数据存储、广告展示及奖励发放功能
隐私政策链接：https://www.taptap.cn/privacy-policy

三、 我们如何共享、转让、公开披露您的信息

我们不会向任何第三方共享、转让或公开披露您的个人信息，除非：
1. 获得您的明确同意；
2. 根据法律法规规定，或应行政、司法机关的合法要求。

四、 我们如何保护您的信息

鉴于本游戏不收集您的敏感个人信息，且游戏存档均在您的本地设备中，我们无需建立庞大的数据安全中心。但我们会尽最大努力保障您设备本地数据的安全。建议您不要使用修改器或第三方外挂修改游戏数据，以免造成设备安全隐患。

五、 您的权利

1. 查询与更正：您可以在游戏内的系统设置或相关界面查看您的游戏进度。
2. 删除：您可以通过卸载本游戏或清理手机应用缓存，彻底删除本地保存的所有游戏数据。
3. 撤回同意：您可以在手机系统设置中关闭本游戏的相关权限（如网络权限，可能导致广告无法加载）。

六、 未成年人保护

我们非常重视未成年人的个人信息保护。本游戏不含任何血腥暴力、赌博等不良内容。若您是未满 14 周岁的未成年人，请在监护人的指导下阅读本政策并使用本游戏。若监护人发现未成年人在未经同意的情况下使用了本游戏，请及时联系我们处理。

七、 隐私政策的更新

我们可能会适时对本隐私政策进行修订。当条款发生重大变更时，我们会在游戏内以弹窗或公告的形式通知您。
